# Clean Portal ZIP — assets

This branch contains the cleaned `index.html` for the SK Free-Wifi Nagsimbaanan captive portal.

Files included:
- `index.html` — cleaned portal page referencing `logo.png`, `pldt-logo.png` and `Saranggola.mp3`.

Please add these asset files to the branch or replace with your own before deploying:
- `logo.png` — SK logo (recommended transparent PNG)
- `pldt-logo.png` — PLDT logo (PNG)
- `Saranggola.mp3` — audio file to play after connect

Once you have pushed assets, you can download the ZIP of this branch using GitHub's archive link:

https://github.com/sknagsimbaananbacnotan/SK-Free-Wifi-Nagsimbaanan/archive/refs/heads/clean-portal-zip.zip

Or download individual files from the branch.
